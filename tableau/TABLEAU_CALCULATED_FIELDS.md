# Tableau Calculated Fields Repository & Specification

## Overview

This document specifies the official Tableau Calculated Fields created for the Online Retail II Tableau reporting suite. Formulas are provided for both summary dataset calculations and granular transaction-level calculations (`retail_cleaned.csv`).

---

## 1. Revenue & Order Calculated Fields

### 1. `Completed Revenue`
- **Formula**:
  ```tableau
  IF [IsCancelled] = FALSE AND [Quantity] > 0 AND [UnitPrice] > 0 THEN 
      [Revenue] 
  ELSE 
      0 
  END
  ```
- **Data Type**: Number (Decimal) | Format: Currency `£#,##0.00`
- **Purpose**: Restricts revenue summation strictly to valid completed sales lines.

---

### 2. `Completed Order Flag`
- **Formula**:
  ```tableau
  IF [IsCancelled] = FALSE AND [Quantity] > 0 AND [UnitPrice] > 0 THEN 
      [InvoiceNo] 
  ELSE 
      NULL 
  END
  ```
- **Data Type**: String
- **Purpose**: Isolates valid invoice numbers for distinct order counting.

---

### 3. `Completed Orders Count`
- **Formula**:
  ```tableau
  COUNTD([Completed Order Flag])
  ```
- **Data Type**: Number (Whole) | Format: `#,##0`
- **Target Value**: **40,067**
- **Purpose**: Calculates total distinct completed invoice count.

---

### 4. `Average Order Value`
- **Formula**:
  ```tableau
  SUM([Completed Revenue]) / [Completed Orders Count]
  ```
- **Data Type**: Number (Decimal) | Format: Currency `£#,##0.00`
- **Target Value**: **£511.04**
- **Purpose**: Computes average revenue generated per completed order.

---

## 2. Contribution & Growth Calculated Fields

### 5. `Revenue Contribution %`
- **Formula**:
  ```tableau
  SUM([TotalRevenue]) / TOTAL(SUM([TotalRevenue]))
  ```
- **Data Type**: Number (Decimal) | Format: Percentage `0.00%`
- **Table Calculation Setting**: Compute using `Table (Down)` or `Country`.
- **Purpose**: Calculates the proportion of portfolio revenue generated by a given country or product.

---

### 6. `Month-over-Month (MoM) Revenue Growth %`
- **Formula**:
  ```tableau
  (SUM([TotalRevenue]) - LOOKUP(SUM([TotalRevenue]), -1)) 
  / 
  LOOKUP(SUM([TotalRevenue]), -1)
  ```
- **Data Type**: Number (Decimal) | Format: Percentage `0.00%`
- **Table Calculation Setting**: Compute using `YearMonth` (Along Table Across).
- **Purpose**: Computes monthly percentage revenue growth rate relative to the preceding calendar month. (Returns `NULL`/`0.00%` for the baseline month Dec 2009).

---

## 3. Date Attribute Calculated Fields

### 7. `Year`
- **Formula**:
  ```tableau
  YEAR([InvoiceDate])
  ```
- **Data Type**: Number (Whole)
- **Purpose**: Extracts calendar year (2009, 2010, 2011).

---

### 8. `Quarter`
- **Formula**:
  ```tableau
  "Q" + STR(QUARTER([InvoiceDate])) + " " + STR(YEAR([InvoiceDate]))
  ```
- **Data Type**: String
- **Purpose**: Formats quarterly string (e.g. `Q4 2009`, `Q1 2010`).

---

### 9. `Year-Month`
- **Formula**:
  ```tableau
  STR(YEAR([InvoiceDate])) + "-" + IF MONTH([InvoiceDate]) < 10 THEN "0" ELSE "" END + STR(MONTH([InvoiceDate]))
  ```
- **Data Type**: String
- **Purpose**: Formats standardized Year-Month string (`YYYY-MM`) for time-series charts.

---

## 4. Quality & Cancellation Calculated Fields

### 10. `Cancellation Rate (Line Level)`
- **Formula**:
  ```tableau
  SUM(IF [IsCancelled] = TRUE THEN 1 ELSE 0 END) / COUNT([InvoiceNo])
  ```
- **Data Type**: Number (Decimal) | Format: Percentage `0.00%`
- **Target Value**: **1.86%**
- **Purpose**: Calculates the proportion of transaction lines that represent order cancellations (`19,100 / 1,027,071`).
