# Processed Data Directory (`data/processed/`)

## Overview

This directory contains the cleaned, deduplicated, and aggregated analytical datasets generated by Phase 2 of the data pipeline (`python/01_data_cleaning_eda.ipynb`). These files serve as the source of truth for the MySQL database, Excel management workbook, Power BI data model, and Tableau analytical specifications.

---

## Important File Exclusion Notice (`retail_cleaned.csv`)

> [!NOTE]
> **GitHub File Size Exclusion**:
> - `retail_cleaned.csv` (135.36 MB, 1.027M transaction rows) is **intentionally excluded from Git tracking** (`.gitignore`) because it exceeds GitHub's 100 MB individual file size limit.
> - **Local Data Preservation**: The local copy of `retail_cleaned.csv` remains preserved in the local environment and is not deleted.
> - **Regeneration Process**: Running the Python pipeline notebook (`python/01_data_cleaning_eda.ipynb`) on the raw Online Retail II dataset (`data/raw/online_retail_II.xlsx`) automatically regenerates `retail_cleaned.csv`.
> - **Summary Analytics**: All included summary datasets (`customer_rfm.csv`, `product_summary.csv`, `country_summary.csv`, `monthly_summary.csv`, `data_quality_summary.csv`) are tracked in the repository and are fully sufficient to power the SQL, Excel, Power BI, and Tableau analytical layers.

## Data Dictionary Highlights

### 1. `customer_rfm.csv`
- `CustomerID`: Unique customer ID (5,878 identified purchasing customers).
- `Recency`: Days inactive relative to reference date (`2011-12-10 12:50:00`).
- `Frequency`: Distinct completed order count (`COUNTD(InvoiceNo)`).
- `Monetary`: Total completed sales revenue (£).
- `CustomerSegment`: 7 categories (`Champions`, `Loyal Customers`, `At Risk Spenders`, `Promising / Average`, `Potential Loyalists`, `Lost Customers`, `Needs Attention`).
- `ChurnRiskProxy`: 4 risk tiers (`High Risk (Churn Proxy)`, `Medium Risk (One-time Inactive)`, `Medium Risk (Dormant Frequent)`, `Low Risk (Active)`).

### 2. `product_summary.csv`
- `StockCode`: Stock item identifier.
- `Description`: Master product description.
- `TotalQuantity`: Total completed units sold.
- `TotalRevenue`: Total completed revenue (£).
- `TotalOrders`: Total completed orders containing item.
- `AvgUnitPrice`: Mean unit price (£).
